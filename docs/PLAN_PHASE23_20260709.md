# Phase 2·3 — 진입 선별성 + 레짐 심화·폭락장 방어 — 개발계획서 v1.0

작성: 2026-07-09 (P0 스케일아웃 루프 수정·배포 완료 후)

## 원본 요구사항 (PM 발화 그대로 인용)

> "너의 제안대로 P0 부터 수정 → 페이즈2,3 계획서 작성 → 페이즈 2개발 하고 테스트 → 페이즈 3개발하고 테스트 → 통합테스트 진행해서 폭락장에서도 최소한 0.5%라도 수익을 낼수 있는 거래엔진을 만들어서 너가 완벽이라고 판단이 된다면 나에게 보고해"

> "거래금액대비 0.5%가 아니야 예수금대비 수익율을 목표로 삼아야해"

> (2026-07-06 확정) "하루 목표 수익률 2%는 계좌 잔고 대비. 전체투자금 및 수익금을 포함해서 매일 복리로 2%씩 증가"

**해석 확정**: 폭락장 목표 +0.5%는 **당일 시작 계좌 잔고(예수금≈총자산, EOD 전량청산 전제) 대비** 수익률. 일일 목표 2%와 동일 분모 체계.

## 배경 데이터 (7/6~7/8 검증)

- 승률 낮음: 손실거래 4~6건/일, 전부 entry_fail 유형. 3일 순손익 -6.1만/-200만/-157만.
- confidence 칼리브레이션은 **기록만** 되고(daily/bins) 자동 반영 없음 (추천만 learning_memories에 승인대기).
- false_positive_cases도 **기록만** — 다음날 진입 반영 배선 없음.
- 레짐 판정·차등 설정은 작동(7/8 risk_off → max_pos 4, 손절 -1.2%). 그러나 `new_entry_allowed`는 **표시용**(미강제), 7/8 negative·risk_off에서도 13건 매수.
- 장중 급락 감지: KOSPI -1.5% 기준·25분 디바운스 — 폭락 초기 대응 느림.
- kospi_change_pct가 S5 RulePack 프롬프트에 공란 주입 가능 (S2 아침 수집만, 개장 후 미갱신).

## 구현 범위

### Phase 2 — 진입 선별성 (목표: entry_fail 감소, 승률 개선)

- [ ] **P2-1 칼리브레이션 게이트**: confidence_calibration_bins의 누적 실적(표본≥30)에서 실제승률이 기대치 대비 gap≥0.15 이상 낮거나 avg_pnl<0인 bin은 진입 차단. `engine.calibration_gate_enabled`(기본 ON), `engine.calibration_gate_min_samples`(기본 30). 적용 지점: `_emit_signal` 단일 길목(모든 진입 경로 커버).
- [ ] **P2-2 entry_fail 심볼 쿨다운**: false_positive_cases에서 최근 N일(기본 3) 내 entry_fail ≥2회 심볼은 당일 진입 차단. `engine.entry_fail_cooldown_enabled`(기본 ON), `engine.entry_fail_cooldown_days`(3), `engine.entry_fail_cooldown_min_count`(2). 적용 지점: `_emit_signal`.
- [ ] **P2-3 레짐별 confidence 하한 상향**: risk_off/volatile 레짐에서 min_ai_confidence에 가산(`engine.regime_confidence_bonus.risk_off`=0.05, `.volatile`=0.10). 적용 지점: `_evaluate_rules`의 ai_conf_min 산출부.

### Phase 3 — 레짐 심화 + 폭락장 방어 (목표: 폭락장 계좌 보존 → +0.5%)

- [ ] **P3-1 kospi_change_pct 공란 수정**: 장중 index-board/market_snapshots의 실시간 KOSPI 등락률을 S5 RulePack 프롬프트(`_format_morning_context_for_prompt`)와 S2 컨텍스트에 명시 주입. 실패 시 "N/A" 명시(빈 문자열 금지).
- [ ] **P3-2 new_entry_allowed 강제**: `engine.enforce_new_entry_allowed`(기본 ON, 롤백 스위치). 이중 가드 — ① `_emit_signal` 초입에서 당일 레짐 SET의 new_entry_allowed=False면 신호 미발행 ② `order_preflight.run_preflight`에 체크 추가(신호가 이미 나온 경우 주문 차단).
- [ ] **P3-3 급락 감지 강화(flash-crash 방어 모드)**: KOSPI ≤ -2.0% 또는 VIX>35 감지 시 — 디바운스 우회 즉시 레짐 재평가 + 알림 + 방어 모드(당일 신규진입 차단 플래그). `risk.flash_crash_threshold_pct`(-2.0), `risk.flash_crash_defense_enabled`(기본 ON). 적용 지점: intraday_regime_monitor.
- [ ] **P3-4 레짐별 수확·빈도 조절**: risk_off/volatile에서 스케일아웃을 더 빨리·더 많이 — regime_set settings에 `scaleout_target_rate`/`scaleout_ratio` 오버라이드 필드 지원(risk_off: 0.015/0.8, volatile: 0.012/1.0 = 전량 익절). position_manager `_scaleout_check`가 당일 적용 SET 값을 우선 사용.
- [ ] **P3-5 폭락장 수익 경로(인버스 1x 플레이북)**: 방어 모드에서 일반 종목 신규진입은 차단하되, **인버스 1x ETF**(레버리지 아님, 예: KODEX 인버스)만 예외 후보로 허용해 하락 추세에서 수익 기회를 확보. `engine.crash_playbook_enabled`(기본 ON·모의계좌), 인버스 2X/레버리지 차단은 유지. 사이징은 계좌의 `engine.crash_playbook_budget_rate`(기본 0.30) 이내.

## 추가 제안 항목 (PM 요청 외)

- **인버스 1x 예외 허용** (P3-5): 기존 레버리지/인버스2X 차단은 유지하되, 폭락 방어 모드에서만 인버스 1x를 허용. 롱온리 현물 봇이 폭락장에서 +0.5%를 낼 수 있는 사실상 유일한 구조적 경로. 설정으로 즉시 롤백 가능.
- **new_entry_allowed 강제 전환**: 기존 "데이터 축적 철학"(미강제)에서 전환. 모의계좌라도 폭락장 방어 검증이 우선이라고 판단. 롤백 스위치 유지.

## 구현 노트 (v1.0 확정)

- P2-3은 "레짐별 하한 가산"에서 **"방어 레짐 한정 confidence 게이트 강제"**로 확정
  (`engine.confidence_gate_mode=regime_defensive`). 평시에는 기존 탐색 철학(관찰용) 보존.
- P3-4 스케일아웃 오버라이드는 regime_sets DB 마이그레이션 대신 **코드 기본값**
  (risk_off 0.015/0.8, volatile 0.012/1.0) + SET `applied_settings` 명시값 우선 방식.
  기존 SET 데이터 변경 없음(forward-only).
- P3-5 인버스 예산 상한(`engine.crash_playbook_budget_rate`)은 설정만 시드,
  사이징 강제 배선은 후속(현재는 레짐 SET max_positions·budget_rate가 노출 제한).
- 모든 게이트 fail-open: 조회 실패 시 차단하지 않음(진입 게이트는 보수적으로,
  손절·청산 안전장치는 별도 경로 유지).
