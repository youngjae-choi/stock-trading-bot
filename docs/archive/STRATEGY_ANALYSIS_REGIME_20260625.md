> 작성 배경: 6/23 KOSPI **-9.3% 폭락장에서 봇이 수익 마감**한 것이 계기.
> 조사 결과 그 생존은 전략이 아니라 **6/22 자동 발동돼 안 꺼진 긴급정지(잔류분)**의 우연이었음이 드러났다.

**분석:**
- 추세를 잡으면(trailing) 건당 **+97K** → **전략 자체는 작동한다.**
- 그러나 초기손절이 **2배 빈도(58 vs 28)** + **1.5배 크기(-150K)** → **손익비가 역전**돼 있다.
- 메커니즘: 진입은 +1.5~8% 모멘텀에서 들어가는데, **트레일링 발동까지 +2.5%** 더 가야 하고 **초기 손절은 -3%**. 정상적인 눌림목 노이즈에서 **트레일링이 발동하기 전에 초기 손절이 먼저 터진다.** → death by a thousand cuts(천 번의 잘린 상처).

## 4. 핵심 발견 ③ — regime 인식이 행동에 배선 안 됨

코드 확인 결과(읽기 전용 탐색):

- `market_tone`(positive/negative/neutral)은 매일 계산되나 **신뢰도가 자주 0.0이고 실제로도 자주 오답**:
  - 6/19 tone=positive → 실제 -0.13% 하락, 봇 -2.29%
  - 6/23 tone=neutral → 실제 -9.3% 폭락
  - 6/24 tone=negative → 실제 +3.71% 급등, 봇 -1.31%
- 장세에 따라 실제로 바뀌는 동작은 **intraday 스파이크 임계 12%→8%(risk_off) 단 하나뿐.**
- 진입 confidence 임계 · 손절/트레일링 % · 포지션 사이징 · 포지션 개수 = **전부 장세 무관 고정.**
- 폭락 방어용 auto-halt는 **-5% 손실 도달 후 발동하는 반응형** — 이미 맞고 나서 막는다. **사전 방어 없음.**

**근거 파일/위치:**
| 영역 | 위치 |
|------|------|
| 진입 신호 emit / 게이트 | `decision_engine.py` `_emit_signal()` (~1657), `_rules_allow_signal()` (~676) |
| 손절/트레일링 | `position_manager.py` (initial -3% / trailing activate +2.5% / trail 3%) |
| 유일한 regime 분기 | `intraday_profile.py:54` (스파이크 12%→8%) |
| 수동/자동 긴급정지 | `order_preflight.py:476` (게이트), `ops_watchdog.py:181` (auto-halt -5%) |
| regime 휴리스틱 | `market_tone.py:72` |
| regime confidence 조정 | `regime_set_service.py` (기록만, **미강제**) |

## 5. 결론 & 권고 로드맵 (구현은 추후 별도 지시)

**2층 구조로 접근 — 토대(장세무관)를 먼저, 장세 플레이북은 그 위에 얹는다.**

### (A) 토대 — R:R 누수 수정 [최우선, 장세 무관]
*PM 결정: 손절폭·진입품질 둘 다 동시.*
- **손절폭 재설계**: 초기 -3% 손절이 트레일링 +2.5% 발동 전에 터지는 구조 해소.
  - 후보: 변동성(ATR 등) 기반 동적 손절, 또는 손절폭 확대 + 익절/트레일링 발동점 재배치.
- **진입품질 강화**: 승률 15~50%를 끌어올림. confidence/거래량/필터 상향으로 "덜 사고 잘 사기".

### (B) 장세별 플레이북 — (A) 위에 얹음
- **장세 신호 기준 (PM 결정): 객관 지표 + LLM tone 하이브리드.**
  - 객관: 실시간 KOSPI 등락·갭·VIX·시장폭(breadth) → 1차 판정.
  - LLM tone: 보조 보정. (단독 신뢰 금지 — 4절 오답 사례)
  - 사전 갭다운 감지로 **폭락 선제방어**(반응형 -5% halt 이전 단계).
- **상승장 (risk_on)**: 손절폭 완화로 추세 라이딩, 자본투입·포지션수 ↑.
- **하락장 (risk_off)**: 사전 자본투입 throttle, 포지션수 ↓, 고확신만, 조기 force-exit, 갭다운 시 선제 halt.
- **혼조/횡보 (volatile/neutral)**: 거래 빈도 ↓, 고확신만, **조기 익절(추세 안 기다림)**, whipsaw 회피. (6/19·6/22 횡보 손실 구간)

### (C) 학습 regime-aware화
- `trade_entry_tags`에 regime은 이미 태깅됨. 이를 **다음날 RulePack/파라미터에 실제 반영**(현재는 태깅만, 행동 미반영).
