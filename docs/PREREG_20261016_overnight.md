# 사전등록 — H-ON 오버나잇 보유 (2026-10-16)

> **결과를 보기 전에 고정한다.** 바꾸면 새 가설이다. 구현 `scripts/overnight_backtest.py`.
> 배경: 1년 분봉(258일)에서 우리 유니버스는 장중 −0.375%/일(t −3.00), 오버나잇 +0.351%/일(t +3.46)
> ([REVIEW_20261016_crash_shadow.md](REVIEW_20261016_crash_shadow.md)). 이 관찰은 **분봉 유니버스(1년)**에서 나왔으므로,
> 이번 시험은 **일봉 2년**(다른 표본 기간 포함)으로 하고, 판정은 2026년 OOS로만 한다.

## 규칙
| 항목 | 값 |
|---|---|
| 데이터 | 일봉(KIS 수정주가) 보통주 2,506종목, 2024-10-07~2026-10-16. 현재 상장 종목만(생존편향, 낙관 방향) |
| 유니버스 U_t | t−1일 거래대금 상위 500 · t−1 종가 ≥ 5,000원 · t일 거래량 > 0 |
| 체결 | t일 **종가(장마감 동시호가)** 매수 → t+1일 **시가(장전 동시호가)** 매도. 동일가중 |
| 제외 | \|시가(t+1)/종가(t) − 1\| > 30% (권리락·데이터 이상) · t+1 시가 없음 |
| 비용 | 왕복 **0.23%**(매일 전량 교체). 스트레스 0.43% |
| 구간 | IS = t ∈ [유니버스 첫 유효일, 2025-12-31] · **OOS = t ∈ [2026-01-01, 데이터 끝 전날]** |
| 통계 | 일별 포트폴리오 순수익 시계열의 평균, Newey-West(lag 5) t |
| 기준선 | KOSPI 지수(0001) 같은 구간(종가→다음 시가) 수익 — **참고 보고**(판정에 쓰지 않음) |

## 판정 (OOS)
- **통과:** ① 순수익 평균 > 0 ② t ≥ **2.5**(이미 많은 가설을 시험했으므로 1개 가설이지만 보수적 기준) ③ IS 순수익 평균 > 0 ④ 스트레스 비용(0.43%)에서도 순수익 평균 > 0.
- **미결:** ①③ 충족, t 1.0~2.5.
- **불통과:** 그 외.
- 통과해도 엔진 반영 없음. 오버나잇 보유는 현 엔진(당일 전량 청산)과 반대 구조 → 갭 하락 위험·사이징 설계·PM 결정 필요.

## 함께 보고(판정 무관)
- 2026-10-07~10-16 폭락 구간 성과, 최대 낙폭(일별 누적), 최악 1일.
- KOSPI 지수 오버나잇 대비 초과(시장 베타인지 확인용).

## 하지 않는 것
